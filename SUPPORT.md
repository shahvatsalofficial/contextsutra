# Support

- **Bugs and questions:** open a GitHub issue at https://github.com/shahvatsalofficial/contextsutra/issues. Never paste secrets or private repository content.
- **Security problems:** do not open a public issue. Use GitHub private vulnerability reporting (see [SECURITY.md](SECURITY.md)).
- **Documentation:** start with [documents/contextsutra/README.md](documents/contextsutra/README.md).
- **Response times:** this is a volunteer open-source project. No service-level agreement is offered.
