    The problem

    AI assistants forget, leak and get misled

    Pasted READMEs go stale, secrets slip into prompts, and a planted line can steer a model. ContextSutra makes each of those visible before it matters.

    Verifiable capsules

    One JSON file with the documents captured, a SHA-256 per source and line references. Facts you can trace.

    Knows when it is stale

    One command lists changed, removed and newly added documents. Exit code 2 makes it a CI gate.

    Secrets stay home

    Secret files are never opened. Secret-looking lines are redacted. A review gate can block sharing.

    Planted instructions held back

    Lines that try to steer an AI are quarantined and never rendered. Repository text is always data.

    Decisions you can trust

    An ADR counts as approved only when its source says so. Tasks stay labelled unverified.

    Works with your tools

    Renders Markdown for any assistant and installs 12 skills for Claude Code, Cursor, Codex, Gemini CLI and Copilot. Host activation is untested.

    How it works

    From repository to trusted hand-off

    Six steps, all on your machine.

    1. 1

      Scan

      Capture docs, decisions and tasks.

      contextsutra scan --root .
    2. 2

      Review and render

      Pass the privacy gate, then export.

      contextsutra review --capsule …
    3. 3

      Verify

      Check freshness any time.

      contextsutra verify --capsule …

    Privacy by design

    What happens to every line

    Deny first, redact second, quarantine third, and only then quote.

    FAQ

    Quick answers

    Does it need an API key or internet?

    No. It runs offline, uses only Node.js built-ins and calls no model.

    Is a capsule safe to share?

    The tool never says so. It can block, and otherwise asks a human to read it. Redaction is best effort.

    How is it different from AGENTS.md or CLAUDE.md?

    Those are written by hand. A capsule is generated, hashed, line-referenced and checkable for staleness.

    Does it work in my IDE?

    It renders Markdown any tool can read and copies skills to documented folders. Whether each host loads them is not yet verified.

    Is the digest a signature?

    No. It is a checksum that detects edits against a trusted copy.

    Can I use it commercially?

    Yes, under Apache-2.0.
